# Çağcan Çal — Portfolio Starter

Modern personal portfolio starter built with Next.js, React, Tailwind CSS and Motion.

## Requirements

- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## First files to edit

- `app/page.tsx` — page sections
- `components/hero.tsx` — hero copy and visual
- `components/navbar.tsx` — navigation
- `app/globals.css` — complete visual system
